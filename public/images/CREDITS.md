## Replacing an image
1. Drop your new file into `public/images/` (keep the same filename, or update the
   path in `src/content/site.ts`).
2. Recommended sizes: `hero.jpg` ≈ 1000×1250 (4:5), `about.jpg` ≈ 900×1080 (5:6),
   `og-image.jpg` = 1200×630 (social preview, fixed ratio).
3. Rebuild: `npm run build`.
